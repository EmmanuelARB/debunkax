# Project status

Read this first when resuming work; it records what git history alone doesn't: what is verified, what isn't, and what's next.

## Where we are

The first version is feature-complete and runs end to end with a real provider on a real device: a Galaxy Tab A11+ running ML Kit, and OpenRouter with DeepSeek V4.1 Flash. A Check is two requests: a search-free pre-check, then a Check searched with Exa. The Verdict bench has run (`spikes/verdicts/RESULTS.md`). The emulator still runs the whole flow with sherpa-onnx.

**Speaker recognition (ADR 0003):** each Claim now names its Speaker, one of 62 enrolled people recognised by voice on the device (the 20 leaders, 23 other politicians and 19 journalists), or "Orateur non identifié". The name shown is the person's name only, whatever their status (the user dropped the "(journaliste)" suffix; rows already saved in the History may still carry it). The name of the current Speaker also shows above the live transcript. The voice prints come from `spikes/speakers/` (`export_prints.py` copies the model and prints into the assets before a build). The next step is to measure the wrong-name rate against speakers the user notes during a real session, then set the threshold, now 0.45 and chosen by ear. First watched session (see below): the attribution followed the debate's order (Le Pen → Glucksmann → Attal, 4 lines unattributed) and the user contested no name — but did not note speakers, so it is still not a measurement.

**First watched session:** 9 min 40 s of the LCI/Medef debate through "Démo audio réelle" on the tablet (ML Kit, real OpenRouter Checks). 25 Claims, 24 checked: 9 accurate, 11 unverifiable, 4 lacks-context, 1 pending; the 4 lacks-context raised the 4 Alerts. The user watched the Alerts live and contested one display: the Alert quoted the third-person rewrite ("Raphaël Glucksmann s'est battu…") instead of the sentence as heard ("Je me suis battu…") — fixed (the quote is now the transcribed sentence; the detail screen shows "Vérifiée sous la forme : …"). The rewrite proved double-edged on this session: it rescued one Check ("Lindsay" → Insee, verified against the Cour des comptes) and overreached on another (inferred "la réforme des retraites" that was never said; Verdict went to History, no Alert). Cost was $0.06 at 4 min 24 s (not persisted, final unknown).

**Second watched session:** a televised debate (socialist primary, David Pujadas hosting) on the tablet through the real microphone, ~14 min. 64 Claims: 19 accurate, 10 lacks-context, 1 false, 33 unverifiable, 1 unchecked. Speaker recognition behaved as designed: every "Orateur non identifié" was either the un-enrolled studio guest (the user confirmed) or a near-tie between two enrolled candidates refused by the 0.10 margin rule (the ~5 hair-broad Guedj refusals are the only true misses); the margin rule's cost on clean clips is measured by a `spikes/speakers/open_set.py` sweep (0.10 / 0.05 / 0.00 at 0.45): leaders named right 82/85/88%, wrong 3.2/5.1/10.4%, unknown 15/10/2%; voices not enrolled get a name in 8.2/27.7/86.9% of windows, before the sentence-level rule. The user chose 0.05: it halves the unknowns (10% / 14%), at the price of wrong names at 5.1/7.4% and un-enrolled voices named in 27.7% of windows before the sentence-level rule. The 33 unverifiables were analysed from the History: the restricted searches all ran and returned allowlist pages, but none contained the fact (each stored context says so) — the biggest fixable class is political events and biography ("I refused an agreement with LFI", "I never joined X"), which only the general press covers. **Trusted Sources widened (on the user's proposal):** the list now includes the major national press — AFP, Le Monde, franceinfo, Libération, Le Figaro, BFM TV, France 24, RFI — in addition to the fact-checking services and official sources; the rubric-only entries (AFP Factuel, Les Décodeurs, Vrai ou Fake, CheckNews) folded into their parent sites. `CONTEXT.md`'s Trusted Source definition was updated to match, dropping the stale "before falling back to open web search" (the provider search has always been hard-restricted to the allowlist, no fallback). Five of the 33 were re-checked through the real pipeline (VerdictBench on `spikes/verdicts/allowlist-widened.json`, DeepSeek V4.1 Flash + Exa): 3 of 5 flipped to grounded verdicts citing the new outlets (1 accurate, 1 misleading, 1 false — the false one, "no complaint against Philippe Brun", verified against the France 24 article), 2 stayed legitimately unverifiable (different scope, or the figure absent from every allowlist source).

**App-audio source (ADR 0004):** starting a Listening Session now asks for the source: **Microphone** (the room, the default) or **Audio des apps** — this device's media playback (YouTube, France.tv Pluzz…) captured through the `AudioPlaybackCapture` API, which is the same 16 kHz mono stream, so speech, Claim filter, speaker recognition and Checks are unchanged. App-audio sessions carry the platform's per-session consent (system dialog, `mediaProjection` foreground service, red recording icon) and end cleanly if the user revokes it; they keep running while the app is in the background, since the video plays in another app. The capture path itself was verified live on the tablet (YouTube audio captured, level meter responding); a full session with Claims/Verdicts from app audio has not been run yet.

**Addressee of « tu » / « vous » (ADR 0006):** second-person Claims ("vous avez voté…") came back unverifiable because the verifier couldn't tell who was addressed. A `HeardClaim` now carries an `addressedSpeaker`, looked up only when the claimant is recognised and the sentence is in the second person: the last *politician* other than the claimant recognised by voice in the 30 s before the sentence, journalists skipped (enrolled speakers carry a `role`, exported by `export_prints.py`). Triage and Check prompts get a "S'adresse probablement à" line; a person named directly in the sentence or just before comes first, and an addressee that stays uncertain ends as unverifiable. Unit-tested (timeline search, second-person detection, session, prompts); not yet measured on a live session.

**Next steps:** fewer false Alerts and better recall (see "Known open points"); stop tuning on the 46-entry bench (overfitting, see `spikes/verdicts/RESULTS.md`); keep judging Alerts from real tablet sessions: two are recorded in `spikes/verdicts/sessions/`, kept locally and not in git (judgments provisional until the user confirms them) and re-checked by `SessionReplay`. Since an Alert must quote a source (`evidence`), 8 of the 10 re-checkable wrong Alerts from those sessions went away. Then the release items under "Waiting on the user".

## Decisions already made (don't re-ask)

- No default Check limit: "Illimité" stays. The app is for a small, deliberate audience.
- Single provider, single model (ADR 0005): OpenRouter only, DeepSeek V4.1 Flash only. Claude BYOK and all other models were removed after the model comparison (`spikes/verdicts/MODELS.md`): V4.1 Flash was the only model at 52 % exact verdicts across two runs, the Claude models cost 8–60× more with no accuracy edge. GPT-5.2 had already been removed (superseded).
- Distribution: direct APK only. Accessibility work was explicitly declined for now.

## Known open points

- Every model misses about half the Claims that deserve an Alert (bench recall 38–69 %), and DeepSeek raises 2–6 false Alerts out of 20 depending on the run. Search results vary between runs, so one bench run can't rank prompts (see `spikes/verdicts/RESULTS.md`).
- Party-group subdomains are excluded: `*.assemblee-nationale.fr` and `*.senat.fr` for Exa (checked live: the www. site stays), `www.` hosts for Claude's `allowed_domains` (from Anthropic's docs, not checked live).

- **Too many "false" Verdicts** (tablet run, DeepSeek V4.1 Flash with the search-free pre-check): 6 of 18 Verdicts were false, and several are doubtful. Some are false only because the sources say nothing ("aucune source ne confirme…"); some for a small approximation (21 % said as 20 %); some from stale or non-comparable data (2017 Insee average against a figure for car-owning households). False Alerts undermine trust. A stricter rule cut this to 4 of 18 on replay, and 0 of 6 on a later demo run. DeepSeek with reasoning did better but took up to 116 s per Check, so it's not usable — retested with `reasoning: {effort: low}` on the golden set: strictly worse (21/46 vs 24 exact, 3 lost Alerts, none gained) at 2× latency and 6× cost, so reasoning stays off (spikes/verdicts/MODELS.md). The Verdict bench (`spikes/verdicts/RESULTS.md`) still shows 4 false Alerts out of 20 for DeepSeek, against 1 for GPT-5.2.
- Cost: that 7-minute run cost $0.15 for 18 Verdicts (about $0.008 each, almost all Exa); the pre-check is negligible. The earlier Haiku run cost about $0.18 for 3 minutes.

- About 150–170 Checks per hour of dense debate: 69% of the sherpa segments pass the filter, because endpoint-cut segments run up to 20 s and bundle several sentences. Cost per Check to be measured by the bench.
- The Verdict golden set is dominated by franceinfo (34 of 36 Claims), itself a Trusted Source, so bench scores will be optimistic.
- Demo modes (`demoMode`, `realAudioDemoMode`) are in-memory only and reset after process death. Debug builds only; acceptable.

## Practical

- **Always pin `ANDROID_SERIAL=emulator-5554` for `connectedDebugAndroidTest` when the tablet is also connected over adb**: without it, AGP runs the tests (and installs the test APK) on *every* connected device. Once, a run without the pin installed the current debug build on the tablet and ran 6 tests on it while the user was at the machine.
- Emulator: `~/Android/debunkax-emulator.sh` (AVD `debunkax`, headless, emulator-5554). A second AVD, `debunkax-test`, exists for the instrumented tests.
- Real-audio demo (silent; runs ML Kit on a phone, sherpa-onnx on the emulator): push a 16 kHz mono WAV as the app's `files/demo.wav` (`adb push` to `/data/local/tmp`, then `adb shell run-as app.debunkax cp /data/local/tmp/demo.wav files/demo.wav`), then turn on Réglages → "Démo audio réelle" (in-memory flag, resets on each restart). The tablet's `demo.wav` is the LCI/Medef debate (Le Pen, Glucksmann, Attal; the file is `spikes/speakers/audio/debate-medef.wav`). For a YouTube video: `yt-dlp -x` then `ffmpeg -ar 16000 -ac 1 -c:a pcm_s16le`. Debate excerpts are in `spikes/stt/audio/` (gitignored).
- Local-only data (gitignored): `spikes/stt/audio`, `spikes/stt/models`, `spikes/claims/data` (labelled sentences), `spikes/claims/out` (transformer checkpoint), and the `.venv`s in `spikes/stt` and `spikes/claims`.
